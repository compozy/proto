# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
By participating you agree to uphold it.

Report unacceptable behavior privately to a maintainer of the
[compozy organization](https://github.com/compozy) through the contact on their GitHub profile.
Every report is reviewed and kept confidential; maintainers follow the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
